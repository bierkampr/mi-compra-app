# Internacionalizacion (i18n)

> Fuente: `lib/i18n.ts`, `locales/es.json`, `locales/en.json`.

---

## Como Funciona

El sistema es completamente custom (sin librerías externas como next-intl o react-i18next).

1. `lib/i18n.ts` exporta una función que, dado un idioma (`'es'` | `'en'`), devuelve la función `txt(key)`.
2. `txt(key)` recibe una ruta de puntos (ej: `'scanner.title'`) y devuelve el string traducido.
3. En `app/page.tsx` se instancia `txt` según el idioma activo y se pasa como prop a todos los componentes.

## Regla de Desarrollo

Todo texto visible en la UI **DEBE** estar envuelto en `txt('modulo.clave')`.
Nunca hardcodear strings en español o inglés dentro de los componentes.

```typescript
// Correcto
<h1>{txt('dashboard.title')}</h1>

// INCORRECTO
<h1>Mi Compra</h1>
```

## Estructura de Locales

Los archivos `locales/es.json` y `locales/en.json` tienen la misma estructura anidada.

```json
{
  "auth": { "login": "...", "logout": "..." },
  "dashboard": { "title": "...", "noExpenses": "..." },
  "scanner": { "capture": "...", "analyzing": "..." },
  "list": { "addItem": "...", "empty": "..." },
  "review": { "confirm": "...", "cancel": "..." },
  "settings": { "language": "...", "account": "..." }
}
```

## Como Agregar un Nuevo Texto

1. Añadir la clave en `locales/es.json`.
2. Añadir la misma clave con la traducción en `locales/en.json`.
3. Usar `txt('modulo.nueva_clave')` en el componente.

## Como Cambiar el Idioma

El idioma actual se guarda en `localStorage` y se cambia desde `SettingsView`.
`page.tsx` lee el idioma al montar y crea la función `txt` correspondiente.
