7. Fondo y Estructura Global (CSS)

  • Fondo Radial Global: El body utiliza un gradiente sutil:
    background: radial-gradient(circle at 50% 0%, #1a1d2e, #0D0F1A 85%); para aportar profundidad desde el top center.
  • Radios de Borde (Border Radius): Todo se siente suave y orgánico utilizando rounded-2xl o rounded-[2rem]. Los bordes cuadrados están prohibidos en este diseño.
  • Desenfocado (Glassmorphism): Para modales y barras de navegación flotantes se utiliza intensamente backdrop-blur-md y sombreados grandes, además de bordes semi-transparentes border-white/[0.05].
  • Librería de Íconos: Se usa Lucide Icons consistentemente para toda la iconografía (stroke, minimalista).
  • Animaciones: Al cargar o interactuar con elementos, el sistema aprovecha active:scale-[0.98] para dar un feedback táctil claro a los botones y tarjetas.
